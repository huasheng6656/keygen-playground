# 02 · 常见注册验证算法

从易到难，这是注册机学习中最常见的几类验证算法。
每一类都给出「程序端长什么样」和「破解/还原思路」。

## 1. 硬编码字符串比较（最简单）

程序里直接写死一个字符串，输入和它相等就通过。

```python
VALID = "H3LL0-K3YG3N-2024"

def check(serial: str) -> bool:
    return serial == VALID
```

- 还原思路：搜索字符串（IDA 的 Strings 窗口 / x64dbg 的字符串引用），或对
  `strcmp / lstrcmp` 下断点，直接看到正确值。
- 对应练习：`targets/easy/`

## 2. 简单变换（异或、加减、逆序）

注册码不是直接比较，而是先对输入做变换再比。例如：

```python
def check(serial: str) -> bool:
    # 每位异或 0x5A 后与内置值比较
    return "".join(chr(ord(c) ^ 0x5A) for c in serial) == "内置密文"
```

- 还原思路：找到变换函数，把变换过程逆过来（异或的逆还是异或）。
- 特点：多出现在老式软件和破解练习中。

## 3. 校验和 / CRC

把用户名（或注册码本身）按某种规则累加，得到校验值，要求等于输入。

```python
def checksum(s: str) -> int:
    return sum(ord(c) for c in s) & 0xFFFF
```

- 还原思路：本质是"一个输入 → 一个定长输出"的映射，逆向很直观。
- 常见变体：CRC16/CRC32、加权和、异或和。CRC 有现成查表法实现。

## 4. 哈希 + 用户名绑定（最经典）

注册码绑定用户名：`注册码 = 哈希(用户名 + 盐)`。验证时重新计算再比较。

```python
def make_serial(username: str) -> str:
    return f"{fnv1a_32(username.encode()):08X}"
```

- 还原思路：认出哈希常量（如 FNV 的 `0x811C9DC5` / `0x01000193`，MD5、SHA 的
  初始向量），用任意语言重写即可。哈希本身不可逆，但注册机**不需要逆**——
  只需要按同一方向计算。
- 对应练习：`targets/medium/`

## 5. 对称加密

注册码是用户名/机器码用固定密钥加密后的结果。

```python
# 伪代码：serial = AES_encrypt(key=内置密钥, data=username)
```

- 还原思路：找到密钥和算法（AES/DES/自写 XOR 加密等）。密钥可能藏在
  二进制数据段里，也可能由固定字节变换而来。
- 注意：只要密钥在客户端，就一定能被提取——这是对称加密用于注册码的先天弱点。

## 6. 非对称签名（RSA，最坚固）

程序内置**公钥**，验证时对注册码做「验签」：只有用作者手里的**私钥**签出来的
注册码才能通过。

```python
# 程序端：verify(用户名, 注册码) = pow(注册码, E, N) == 填充后的哈希
# 作者端：sign(用户名) = pow(填充后的哈希, D, N)
```

- 还原思路：光有公钥**无法伪造注册码**（私钥不在程序里）。所以这类软件
  要么靠提取泄露的私钥，要么靠 Patch 跳过验证，要么走内存注册机。
- 这就是为什么现代软件用 RSA 后，"注册机"越来越少见。
- 对应练习：`targets/hard/`

## 7. 挑战-响应（Challenge-Response）

程序随机出一个挑战值，注册机必须给出对应的响应。

- 优点：无法复制粘贴别人的注册码。
- 还原思路：响应函数仍然内置在客户端，可以提取后做成"响应生成器"。

## 8. 在线验证（服务器端）

注册码是否有效由服务器判定，客户端拿不到任何算法。

- 还原思路：本地无法做算法注册机，通常只能改客户端行为（伪造响应）或分析
  网络协议，这已经超出注册机范畴。

## 小结

| 算法 | 能否做算法注册机 | 还原重点 |
|------|------------------|----------|
| 硬编码比较 | 能 | 找字符串 |
| 简单变换 | 能 | 逆变换 |
| 校验和/CRC | 能 | 复现计算 |
| 哈希绑定 | 能 | 认出哈希、复现 |
| 对称加密 | 能 | 找密钥 |
| RSA 验签 | 通常不能（需私钥） | Patch / 内存注册机 |
| 在线验证 | 不能 | 改客户端 / 协议分析 |
