# 03 · 逆向分析工具

注册机分析一般分**静态分析**（不运行程序）和**动态分析**（运行并调试）两条路线。
下面按用途列出常用免费工具。

## 1. 查壳 / 识别编译器

- **Detect It Easy (DIE)**：识别程序是用什么写的、有没有加壳（UPX、Themida 等）。
- **PEiD**：老牌，功能略弱但仍在用。
- 为什么要先查壳：加壳程序直接反汇编会看到一堆垃圾代码，要先脱壳或带壳调试。

## 2. 静态分析（读汇编 / 伪代码）

| 工具 | 适合对象 | 说明 |
|------|----------|------|
| **Ghidra**（免费） | 通用 | NSA 出品，反编译成 C 风格伪代码，支持 Python 脚本 |
| **IDA Free / IDA Pro** | 通用 | 行业标准，免费版功能受限但够学习用 |
| **dnSpy** | .NET 程序 | 直接反编译回 C#，几乎等于看源码 |
| **JADX** | Android APK | Java/Kotlin 反编译 |
| **strings / 十六进制查看器** | 一切 | 先看字符串往往最快 |

静态分析第一步永远是：**看字符串**。错误提示「注册码无效」旁边往往就是验证代码。

## 3. 动态分析（调试）

| 工具 | 适合对象 | 说明 |
|------|----------|------|
| **x64dbg / x32dbg** | Windows 原生程序 | 最流行的调试器，断点、单步、内存修改 |
| **OllyDbg** | 老式 32 位程序 | x64dbg 的前辈 |
| **WinDbg** | 内核 / 驱动 | 进阶 |
| **Frida** | 安卓 / 通用 hook | 运行期 hook 函数、改返回值 |

动态分析核心技能：

- 下断点：断在比较函数、MessageBox、输入读取 API 上。
- 看寄存器 / 栈：找到"正确注册码"或关键计算结果。
- 改内存：把比较结果改成通过（内存注册机的原理）。

## 4. 常用辅助

- **Process Monitor**：看程序读了哪些文件、注册表（找机器码来源）。
- **Wireshark**：抓网络包（对付在线验证）。
- **UPX / 各种脱壳机**：给练习目标脱壳。

## 5. 针对本仓库

本仓库的 `targets/` 是 Python 源码，直接读源码即可理解算法。
想练真机逆向，用 `tools/build_exe.ps1` 打包成 `.exe`（PyInstaller），
然后按下面流程走：

1. DIE 查壳 → 会发现是 PyInstaller 打包。
2. 用 `pyinstxtractor` 解包，或直接调试。
3. 定位验证逻辑，还原算法。

PyInstaller 打包的程序比原生 C 程序难调一些，建议之后再用 C 写一个目标练手
（`docs/04` 最后有 C 版建议）。
